# Group E Python Assessment

A small collaborative coursework repository centered on a Jupyter notebook.
The notebook's exercise demonstrates a basic rate calculation: estimate
elapsed time by dividing a stated number of combinations by a stated
combinations-per-second rate.

## Repository contents

- `python_assesment.ipynb` — the assessment notebook and its example output

## Learning objective

The exercise practices:

- collecting numeric input
- using division to calculate an estimated duration
- displaying a result
- documenting code with comments

The mathematical relationship is:

```text
estimated time = number of combinations / combinations processed per second
```

This is a simple arithmetic demonstration, not a password recovery or
security-testing utility. Any real security assessment must be explicitly
authorized and follow the relevant organization's rules.

## Notebook status

The notebook is an early coursework artifact and may need cleanup before it
can be run from a fresh Jupyter environment. It has no dependency manifest or
automated test suite. Open it with Jupyter Notebook or JupyterLab and review
the code cell before execution.
